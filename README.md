# laptop-doctor — «Здоровье ноутбука»

Значок в трее KDE Plasma, который следит за состоянием Linux-ноутбука, умеет исправлять известные проблемы
и чистить диск. Цвет значка: зелёный — всё в порядке, жёлтый — внимание, красный — проблема.
О новых проблемах приходит уведомление.

Появился как замена ручной диагностике: внезапные перезагрузки, горячий процессор, контейнеры в цикле
перезапуска, упавшие сервисы, забитый диск.

## Проверки (каждые 5 минут)

| Проверка | Что смотрит |
|---|---|
| Жёсткие сбросы | загрузки, журнал которых оборвался без штатного выключения; отдельно — после применённого фикса |
| Дискретная видеокарта | обесточена ли (D3cold), не привязался ли драйвер снова |
| Температура | текущая, p95 за последний час (статус), статистика за день, троттлинг процессора |
| Память и swap | занято/доступно, swap, давление памяти (PSI), убийства по нехватке памяти, кто больше всех занимает |
| Тесты | запущенные тесты (phpunit, pytest, jest, vitest, playwright…) и CI-контейнеры: сколько памяти, не зависли ли |
| Незапушенная работа | репозитории в `project_roots` с давно не закоммиченными правками, неотправленными коммитами, без remote (git читается без блокировок) |
| Здоровье SSD | NVMe SMART через UDisks2 без root: износ, резерв, ошибки носителя, перегрев, небезопасные выключения |
| Ошибки ядра | ошибки с момента загрузки: серьёзные (железо, диск, GPU) отдельно, шум загрузки отдельно, свой список игнора |
| Обновления | apt (сколько безопасности), snap, flatpak, прошивки fwupd; кнопка открывает Discover |
| Батарея | порог заряда, износ, циклы |
| Docker | циклы перезапуска (с хвостом лога), нездоровые по healthcheck, пожиратели CPU, вернувшиеся заброшенные проекты |
| Сервисы | упавшие (system и user), снова включённые отключённые |
| Прочее | место на диске, размер журнала, время загрузки, профиль производительности, нужна ли перезагрузка |

Для известных проблем есть кнопка исправления: вернуть порог заряда, отключить вернувшиеся сервисы,
перезапустить упавшие, остановить контейнеры, ограничить журнал.

## Зависшие тесты и нехватка памяти

Пункты «Остановить тесты…» и «Вернуть swap в память…» есть в меню значка (правый клик) — доступны всегда.

Быстрый сторож раз в 15 секунд читает `/proc/meminfo` и `/proc/pressure/memory` (почти бесплатно) и при нехватке
памяти сразу присылает уведомление. Кнопка «Остановить тесты и освободить память» останавливает найденные тесты
(SIGTERM, через 5 с SIGKILL; CI-контейнеры — `docker rm -f`), а затем, если в swap много данных и они помещаются
в RAM, возвращает их в память (`swapoff`/`swapon`, помощник перепроверяет запас перед этим).

С `"auto_stop_tests_on_memory_critical": true` тесты останавливаются автоматически, когда доступно меньше 5% памяти
или процессы ждут память больше 20% времени.

## Очистка

Сначала «Посчитать» (в фоне), потом отметить и «Очистить выбранное»:

- Docker: образы без тега, кэш сборки, безымянные тома с `node_modules` и кэшами Next.js.
  Содержимое томов проверяется перед удалением — тома с базами данных не трогаются;
- старые версии snap-пакетов, `apt autoremove`, аварийные отчёты из `/var/crash`;
- корзина, кэши pip / uv / npm / yarn / Gradle, миниатюры;
- мусор сборки (`node_modules`, `.venv`, `target/`, `.dart_tool`, `build/`, `.next`) в проектах, не менявшихся
  30+ дней; проекты с работающими контейнерами не трогаются.

Плановая очистка (`auto_clean_enabled`) раз в неделю чистит безопасные кэши без пароля и присылает отчёт.

## История

Вкладка «История»: графики за 24 часа / 7 / 30 дней — температура CPU (из журнала `hw-watch`), доступная память
и swap (программа записывает замер после каждой проверки в `~/.local/state/laptop-doctor/history.jsonl`),
жёсткие сбросы по дням. Наведение показывает значение; разрывы линий — ноутбук был выключен.

## Безопасность

- Проверки только читают систему. Любое изменение — по кнопке и после подтверждения.
- Действия от root выполняет `/usr/local/libexec/laptop-doctor-helper` через `pkexec`: фиксированный список
  действий, аргументы строго проверяются. Пароль запрашивает polkit.
- Пользовательская очистка удаляет только пути внутри `$HOME`.

## Требования

KDE Plasma (или другой трей с StatusNotifierItem), Python 3.11+, PyQt6 (`sudo apt install python3-pyqt6`),
polkit (`pkexec`). Docker, snap и `power-profiles-daemon` — по желанию: без них соответствующие проверки
просто пропускаются.

Температура за час и за день берётся из журнала сервиса `hw-watch` — любой юнит, который раз в несколько
секунд пишет в журнал строку вида `x86_pkg_temp=72 TCPU=70 ...`. Без него показывается только текущая.

## Установка и запуск

```bash
git clone https://github.com/svv2602/laptop-doctor.git && cd laptop-doctor
./install.sh              # помощник + polkit (sudo), команда laptop-doctor, ярлык в меню, автозапуск
laptop-doctor &           # трей
laptop-doctor --check -v  # отчёт в терминале
python3 -m pytest tests   # тесты
```

После изменения помощника снова запустите `./install.sh`.

## Настройки

`~/.config/laptop-doctor/config.json` создаётся при первом запуске. Пример личных настроек:

```json
{
  "fix_applied_since": "2026-11-12 12:31:00",
  "dgpu_pci": "0000:04:00.0",
  "battery_threshold": 80,
  "abandoned_compose_projects": ["old_project"],
  "stopped_containers": ["myapp-elasticsearch-1"],
  "disabled_units": ["ollama.service", "NetworkManager-wait-online.service"],
  "project_roots": ["~/Projects", "~/FlutterProjects"],
  "kernel_error_ignore": ["FAN0\\._FST"],
  "auto_clean_enabled": true,
  "test_container_prefixes": ["ci-"],
  "test_container_images": ["(^|/)ci-php"],
  "auto_stop_tests_on_memory_critical": false
}
```

Пустые списки и строки отключают соответствующую проверку.
